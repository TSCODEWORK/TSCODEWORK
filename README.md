### Open-Source Tools

* **[Solar Calculator](https://github.com/TSCODEWORK/solar-calculator)** — Interactive solar & battery storage payback engine modeling physical degradation and utility inflation, backed by an automated weekly GitHub Actions refresh from NREL PVWatts & EIA data (`Next.js 16` · `React 19` · `TypeScript` · `Tailwind CSS v4` · `Recharts`).
* **[SVRN](https://github.com/TSCODEWORK/SVRN)** — Portable offline knowledge and local AI workspace for macOS bundling local LLMs, offline libraries, and maps with zero internet required (`macOS` · `Swift` · `Python` · `Ollama`).
